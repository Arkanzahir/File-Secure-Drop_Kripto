FILE SECURE DROP

Berbagi, sesederhana itu.

Pilih file, tentukan penerima, lalu kirim. Penerima menemukan kirimanmu di kotak masuk.

01

Pilih file

Gunakan tombol Pilih file atau tarik dari perangkatmu.

02

Tentukan penerima

Tambahkan pesan singkat bila diperlukan.

03

Kirim & pantau

Lihat status kiriman melalui menu Terkirim.

Mencoba kirim dan terima

Masuk sebagai Bob, kirim file kepada Alice, lalu pilih Akun: Alice dan buka Kotak masuk. Kamu juga bisa membuka dua tab dengan akun berbeda. Maksimal 1 MB per kiriman.
